LightAlbum 开场动画方案 · 分镜故事板

现有 P13：淡入 + 翡翠呼吸 → 收缩成缝 → 客户端从缝展开（约 3.1s，kSplash* 常量）。
下图 5 个方向均复用 SplashWindow 与已验证的「缝」衔接；A 为现状保留，B–E 换视觉母题。
方案视觉母题 / 气质关键动作与「缝」衔接实现量风险
A 墨韵呼吸·裂屏
(现状)		沉稳留白淡入 + 翡翠呼吸 → 成缝复用已上线无
B 光圈开合·镜头唤醒摄影 / 镜头感光圈叶片开合露出品牌 → 虹膜塌缩成缝复用（虹膜塌缩≈缝）中叶片几何计算
C 胶片划过·帧闪胶片怀旧胶片条划过 + 样张帧闪 → 成缝复用中取样图加载时序
D 光斑汇聚·博克梦幻 / 光多博克光斑汇聚成辉光 → 成缝复用小低
E 缩略拼贴·网格直接秀照片缩略图飞入拼成网格 → 直接展开进图库改为直接进（跳过缝）大重，改 handoff
推荐：B 或 D。 两者都换掉「现状呼吸」的单一母题、带来新鲜感，又完全复用已验证的「缝 → 客户端展开」衔接，改动只落在 SplashWindow 内部，风险最低最稳：
· B 光圈开合 最贴「摄影 app」身份，镜头/光圈的语言和「光影集」品牌天然咬合；峰值帧画一个开合光圈即可，衔接时把光圈塌缩成缝。
· D 光斑汇聚 最轻盈梦幻，实现量最小（在现有呼吸辉光基础上加几个可动的博克光斑 + 汇聚 tween），几乎零风险。
· 若想最直接地证明「这是你的照片馆」，选 E（缩略图网格），但工作量最大，且要把 main.cpp 的「缝展开」改成「直接进图库」。
注：以上时间均沿用现有 kSplash* 常量（约 3.1s）；无障碍「减弱动效」仍走 playStatic() 静态品牌画面。
