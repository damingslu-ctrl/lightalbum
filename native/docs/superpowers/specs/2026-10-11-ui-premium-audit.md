## 2. 结构性设计债（静态盘点，数字为证）

1. **设计系统名存实亡**：`Theme.h` 19 枚 token，但 `src/ui` 里有 **434 处 hex 字面量、75 个不同值，其中约 53 个 off-token**；「在 token 上」的页面也仍在贴字面量（`#4fc08a`×46、`#f4f7f4`×45）。**RetouchPage 90 hex / 0 token 引用（未 include Theme.h）**，MapPage 68/1。
2. **一个拼错的颜色成了事实规范**：`#8da996`（MUTED `#8da396` 的 typo）×22 处，是图库/选片/去重实际的次级文字色。
3. **两套并行的字号系统**：QSS 12 档 px（9–18 含 11.5）+ 代码 29 处 setPointSizeF（pt 单位 8.5–20），无命名阶、无 body/caption/display 语义；font-weight bold/600/700 混用。
4. **无间距栅格**：QSS 27 种 px 值（3/5/6/7/9/11/13 全在役），非 4px 网格；圆角 **17 个不同值**（8/9/10/11/12 并存 + 15/17/22/24 离群）。
5. **零高度体系**：全仓 0 处 QGraphicsDropShadowEffect，深度靠 MapView 里 off-token `#5fdca6` painter 辉光硬画。
6. **同组件多配方**：ghost 按钮 6 套 QSS、滑杆本地重写 3 处（Theme 已有 `slider()`）、输入框 3 变体、进度条 2 份。
7. **emoji 图标 34 处 / 12 文件**（★🔒▶▢✕✂🖌🧹…），D4 的根因。

**热点排序**（影响×数量）：RetouchPage > MapPage > GalleryPage（含 8 色 off-token chip 板 + 4 份克隆 chip CSS）> CullPage > MainWindow。

## 3. 升级路线（子轨分解，各自独立立项交付）

- **P0 缺陷修复轨**：D1–D3、D5（纯布局/颜色修正，不动设计语言；每条配可断言的截图或几何断言）。
- **P1 设计语言 v2（tokens）**：语义化色板（surface 0/1/2、text 主/次/弱、jade/gold 双强调）+ 命名字阶（display/serif-title/body/caption…）+ 4px 间距阶 + 5 档圆角 + **首个 elevation 阴影预设**；收编 53 枚 off-token 色、退役 `#8da996`；组件单源（btnGhost/slider/input 各一份）。**新增脚本门禁：src/ui 禁 off-token hex（白名单递减棘轮）**——把「规范」变成可跑红的契约，与仓库门禁文化同构。
- **P2 图标体系**：34 处 emoji → qrc 内嵌 SVG（qsvgicon 已随包），窗口控制/隐私锁/播放器/工具按钮全覆盖，杜绝豆腐块。
- **P3 逐页精修**（每批一个循环，用新 token 重写）：批A 图库+**新设置页**（设置页直接按新语言出生）；批B 选片+修图；批C 足迹+日志；批D 关于页重塑+首页微调。
- **P4 收口**：WCAG 对比度复检 + 高 DPI 三档 + 减动效回归 + 全量 71 门 + 新门禁入册 + 发版。

**硬约束（全程不破）**：71 道既有 QA 门全绿；数据契约/零云端立场/i18n 单源不动；视觉改造只改层不碰骨。
