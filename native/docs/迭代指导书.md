# LightAlbum native（Qt 6.8.3 / MinGW）迭代指导书

> 适用范围：光影集桌面端 `native/`（C++ / Qt 桌面应用），当前重心为**足迹地图模块**。
> 原则：**先取证再下结论、先测量再优化、改完必须实测、结论必须可复现**。
> 所有命令/路径/期望值均为本机实测，未经验证的推断一律标注「推测，验证方式：…」。

## 0. 铁律速查（踩过坑才写进来，改代码前先扫一遍）

| # | 铁律 | 来源（回归事故） |
|---|---|---|
| 1 | **命中测试与绘制必须共用同一套变换数学**（scale/dst/offY/drift） | 世界层命中用 `rect().height()`、绘制用 `dst.height()` → 热区偏移 ~30px，点金点无反应 |
| 2 | **复用层级实现新视图时，所有 `level_==X` 守卫必须重审** | `startBurst`/`paintEvent`/`drawBurst` 三处只认省视图 → 国家视图爆炸从未播放 |
| 3 | **零尺寸 `QRectF` 并集必须显式 min/max** | `computeProvinceBBox` 被 `isEmpty()` 短路 → bbox 退化单点 → 省点不动 |
| 4 | **`QPainter` helper 一律 `save()/restore()`** | `drawLabel` 泄漏 cream 笔刷 → 后续省面被整片误填充 |
| 5 | **容器级 QSS 禁用裸类型选择器**，一律 `setObjectName` + `#id{}` | `QWidget{...}` 命中全部后代 → 框中框 |
| 6 | **mapdata.json `provinces` 必须双层 `[[flat],...]`** | GeoIndex（`photo.prov` 反查）按双层解析；扁平格式静默丢省 |
| 7 | **中文比较直接写 UTF-8 源码**，勿用 `\xNN` 字节转义 | `QStringLiteral("\xe9\x9d\x92")` 按 UTF-16 码点解释 → 永远比较失败 |
| 8 | **每帧 paint 内禁止 O(n) 重建/重算/整向量复制/逐条描边上千图元** | region 帧耗 52.9ms；静态 bake 一次 + 动态合批后 0.45ms |
| 9 | **装饰元素随 zoom 用 `sqrt(scale)` 增长**，勿线性 | 下钻放大后光晕变 100+px 巨斑 |
| 10 | **同一数据文件多消费方，过滤条件必须两端同步** | 转换器 `len(xy)>=4` 才 append ↔ C++ 跳过 `exterior<3`，否则 worldNames 索引错位 |
| 11 | **离屏门测渲染/性能必须 `resize(1200,800)`** | 堆叠页非当前页尺寸极小 → 帧耗时测出 0.00ms |
| 12 | **缓存失效入口必须唯一**：改数据一律经 setter（`setGpsPoints`），禁止直接赋值成员 | QA 直接赋值 `gpsPts_` → `densDirty_` 未置位 → 沿用了真实库 6425 点的旧密度，jade 17→51（可复现性被破坏） |
| 13 | **补丁脚本的多行串要按 CRLF 构造** | 三引号 LF 文本在 CRLF 源码里匹配 0 次（`assert(count)` 能立刻暴露） |
| 14 | **语义从「按下即生效」改为「松开生效」时，QA 合成必须发 press+release** | 点空白改为待命平移后，`blank` 断言只发 press → 假 FAIL（探针增加 `sendTap`） |
| 15 | **断言取值要在动作之前**：进入下钻视图会重置 zoom | `vzoom` 断言在点击后才读 `viewZoom_`，永远读到 1.00 |

## 1. 迭代流程（8 步，一步都不省）

```
① 对齐需求 → ② 现状取证 → ③ 根因定位 → ④ 方案（主+备选，写清取舍）
→ ⑤ 实施（小步、可回退）→ ⑥ QA 实测（门 + 新增断言）→ ⑦ 打包/提交 → ⑧ 记忆 + 台账
```

- **① 对齐需求**：功能是什么、目标层级、约束（能否改数据结构/升版本）。影响面大的先讲后做。
- **② 取证**：读代码到具体行；要日志/计数/截图；**禁止凭印象下结论**。
- **③ 根因**：能回答「为什么是它」，引用具体代码行/API 行为；区分「已确认」与「推测」。
- **④ 方案**：至少一个主方案 + 风险点 + 需要用户拍板的地方。
- **⑤ 实施**：一次一件事；改完立刻 `grep -n` 核验（见 §5 补丁规范）。
- **⑥ QA**：跑对应门；**新增 bug 必须新增一条可断言的 QA**（不许只靠肉眼）。
- **⑦ 打包**：`release.ps1` 重出 zip；`git commit` 写清「现象→根因→改法→实测数据」。
- **⑧ 记忆**：`.workbuddy/memory/YYYY-MM-DD.md` 追加；跨迭代沉淀进 `MEMORY.md`；本文件 §7 台账留一行。

## 3. QA 门清单（离屏，命令 + 当前期望值）

执行范式（**必须后台 + sleep + taskkill**，避免挂死）：

```bash
(QT_QPA_PLATFORM=offscreen LA_XXX=arg ./build/LightAlbum.exe > /tmp/x.log 2>&1 &) ; sleep 8
grep -a "LA_XXX" /tmp/x.log ; taskkill //F //IM LightAlbum.exe >/dev/null 2>&1
```

| 门 | 命令 | 期望（当前基线） |
|---|---|---|
| 结构烟雾 | `LA_MAP_SMOKE=1` | `rings=2608 regions=10 provinces=233 zh=233 names=2596` |
| 世界烘焙 | `LA_MAP_A_QA=<png>` | `jade>0 points=5`（jade≈17） |
| 大区省视图 | `LA_MAP_REGION_QA=<png>[,<id>]` | `provinces=34 land≈153080`（默认 china） |
| 点击链路 | `LA_MAP_CLICK_QA=1` | 10 项全 OK（见下） |
| 爆炸弹层 | `LA_MAP_BURST_QA=<png>` | `gold>0 emerald>0 cream>0` |
| 国家视图 | `LA_MAP_COUNTRY_QA=<png>[,<名>]` | `slate>0`（默认 India） |
| 帧耗时 | `LA_MAP_PERF=1` | world/region/province/country（1200×800） |
| 全局烟雾 | `LA_SMOKE=1` | `photos=6425` 等 |

`LA_MAP_CLICK_QA` 十断言：`country / anchor / province / burst / card / blank / zoom / all / ctry / cburst`。

**离屏环境坑**
- 日志含二进制字节 → `grep -a`；`timeout`/管道吞 stderr → 用 `export VAR && exe 2>&1 | grep -a`。
- `grab()/render()` 截图族易挂（rc=124）→ 改用离屏 `QImage` + 内部绘制函数渲染。
- 门控要在 `main.cpp` 的 `animOk` 条件里并列排除，否则被开场动画分支拦截。

## 4. 编码规范（地图模块）

- **坐标**：预投影 `eqX(lon)=(lon+180)/360*1000`、`eqY(lat)=(90-lat)/180*500`，`MAP_W=1000, MAP_H=500`。
- **世界变换**（唯一真源）：`scale = dst.height()/MAP_H*worldZoom_`，`dst=rect().adjusted(8,8,-8,-8)`；横向 `driftPx_`（回绕）、纵向 `worldOffY_`（`worldOffYClamped()` 夹取）。
- **分层**：静态 = 网格/省面/国界/标签/足迹点（bake 进 `viewPix_`）；动态 = 航线流动虚线 + 爆炸弹层。
- **缓存失效**：`invalidateViewCache()` 于 enter*/goUp/resize/setGpsPoints；`densDirty_`、`arcTargetsDirty_` 于 setGpsPoints/setArcRegionIds。
- **交互语义**：世界点国家→（专辑 10 国）省视图 /（其余）国家视图；省面点→省视图；空白→返回上一级；爆炸卡片→灯箱。
- **动效**：`reduceMotion_` 时直达终态；`MotionPref.h` 常量集中管理。

## 5. 补丁操作规范

- 源文件 **CRLF**；多行 heredoc 易失配 → 用 Python「读 → 替换 → `assert(count==1)` → 写回」。
- `Edit` 工具存在**静默不落盘**：改完必 `grep -n` 核验；CRLF 文件长片段匹配失败时改单行锚点。
- 头文件改信号/方法后必查**重复声明**（`cannot be overloaded` 典型报错）。

### 迭代 1 执行记录（按 §1 八步）

1. **对齐需求**：世界层可滚轮缩放(1–4x)、可拖拽平移，但无「回到默认视角」入口，缩放倍数不可见 → 平移/缩放后易迷路。
2. **取证**：`worldZoom_/worldOffY_/driftPx_` 三个状态无复位路径；底部提示只写「滚轮缩放 · 拖动平移」。
3. **根因/方案**：补 `resetWorldView()`（zoom=1 + `centerWorldOn(默认中心)` + offY 归零）；MapPage 顶部栏按钮仅世界层可用；底部右侧显示 `缩放 ×N`。
4. **实施**：MapView（`defaultCenterX()` 抽公共、首帧初始化复用）+ MapPage（按钮/槽/enable 联动）。
5. **QA 意外收获**：新增 `reset` 断言时发现两处真实隐患——① 断言读了夹取前的 `worldOffY_`（应读 `worldOffYClamped()`）；② **QA 直接赋值 `gpsPts_` 绕过 `setGpsPoints`，使密度缓存沿用真实库 6425 点的旧值**（jade 17→51，可复现性破坏）。两处都已修，jade 回到 17。
6. **实测**：十一断言全 OK；perf world=2.35 / region=0.35 / province=0.35 / country=0.30 ms；region provinces=34 land=157234；country slate=27182；burst 分色绿；smoke 不变。
