# LightAlbum native（Qt 6.8.3 / MinGW）迭代指导书

> 适用范围：光影集桌面端 `native/`（C++ / Qt 桌面应用），当前重心为**足迹地图模块**。
> 原则：**先取证再下结论、先测量再优化、改完必须实测、结论必须可复现**。
> 所有命令/路径/期望值均为本机实测，未经验证的推断一律标注「推测，验证方式：…」。

## 0. 铁律速查（踩过坑才写进来，改代码前先扫一遍）

| # | 铁律 | 来源（回归事故） |
|---|---|---|
| 1 | **命中测试与绘制必须共用同一套变换数学**（scale/dst/offY/drift） | 世界层命中用 `rect().height()`、绘制用 `dst.height()` → 热区偏移 ~30px，点金点无反应 |
| 2 | **复用层级实现新视图时，所有 `level_==X` 守卫必须重审** | `startBurst`/`paintEvent`/`drawBurst` 三处只认省视图 → 国家视图爆炸从未播放 |
| 3 | **零尺寸 `QRectF` 并集必须显式 min/max** | `computeProvinceBBox` 被 `isEmpty()` 短路 → bbox 退化单点 → 省点不动 |
| 4 | **`QPainter` helper 一律 `save()/restore()`** | `drawLabel` 泄漏 cream 笔刷 → 后续省面被整片误填充 |
| 5 | **容器级 QSS 禁用裸类型选择器**，一律 `setObjectName` + `#id{}` | `QWidget{...}` 命中全部后代 → 框中框 |
| 6 | **mapdata.json `provinces` 必须双层 `[[flat],...]`** | GeoIndex（`photo.prov` 反查）按双层解析；扁平格式静默丢省 |
| 7 | **中文比较直接写 UTF-8 源码**，勿用 `\xNN` 字节转义 | `QStringLiteral("\xe9\x9d\x92")` 按 UTF-16 码点解释 → 永远比较失败 |
| 8 | **每帧 paint 内禁止 O(n) 重建/重算/整向量复制/逐条描边上千图元** | region 帧耗 52.9ms；静态 bake 一次 + 动态合批后 0.45ms |
| 9 | **装饰元素随 zoom 用 `sqrt(scale)` 增长**，勿线性 | 下钻放大后光晕变 100+px 巨斑 |
| 10 | **同一数据文件多消费方，过滤条件必须两端同步** | 转换器 `len(xy)>=4` 才 append ↔ C++ 跳过 `exterior<3`，否则 worldNames 索引错位 |
| 11 | **离屏门测渲染/性能必须 `resize(1200,800)`** | 堆叠页非当前页尺寸极小 → 帧耗时测出 0.00ms |
| 12 | **缓存失效入口必须唯一**：改数据一律经 setter（`setGpsPoints`），禁止直接赋值成员 | QA 直接赋值 `gpsPts_` → `densDirty_` 未置位 → 沿用了真实库 6425 点的旧密度，jade 17→51（可复现性被破坏） |
| 13 | **补丁脚本的多行串要按 CRLF 构造** | 三引号 LF 文本在 CRLF 源码里匹配 0 次（`assert(count)` 能立刻暴露） |
| 14 | **语义从「按下即生效」改为「松开生效」时，QA 合成必须发 press+release** | 点空白改为待命平移后，`blank` 断言只发 press → 假 FAIL（探针增加 `sendTap`） |
| 15 | **断言取值要在动作之前**：进入下钻视图会重置 zoom | `vzoom` 断言在点击后才读 `viewZoom_`，永远读到 1.00 |
| 16 | **i18n 新串必须 `translate("LightAlbum", "中文")` 字面量直调**，禁经 lambda 形参传入 | `mkSeg(const char* src,…)` + `translate(ctx, src)` → lupdate 静态抽取看不穿形参（变量非字面量）→ 新串**根本没进字典**而 `lupdate` 仍报 "2 new"（那两条是别的串），英文模式静默回落中文硬编码 |
| 17 | **`lupdate` 禁加 `-locations none`**（本项目 ts 刻意保留 299 个 `<location>`） | 会剥掉全部 location（实测 -306 行噪音），须 `git checkout` 回滚；追加 message 的锚点用 `rindex('</message>')`+`index('</context>')`，**禁** `'</message>\n</context>'`（CRLF 文件上会插到最后一条 message **内部** → `lrelease error: Unexpected tag <message>`） |
| 18 | **lambda 返回值用 `auto` 不用 `auto*`** | `auto* f = [&](…){ return btn; }` → `error: unable to deduce 'auto*' from '<lambda closure object>'`（闭包类型无法推导指针） |
| 19 | **逐帧动态元素（播放头/动画/流动虚线）禁入静态烘焙层**（`bakeViewPix`/`buildWorldPixmap`），只能画在 `paintMap` 动态段 | 静态层是「每视图只栅格化一次」的缓存；把动画元素放进去 → 每帧重栅格化整条轨迹，`LA_MAP_PERF` 预算被击穿（实测 world 从 2.0ms 起跳） |
| 20 | **动画位置计算必须是纯函数并同时被绘制与门禁调用** | 门禁自己重算一套坐标 → 与实现漂移时给出**假绿**；`trackPosAt(frac)` 一处定义两端共用（契约同源铁律的动画版） |
| 21 | **过滤/筛选必须在数据注入点做，且多个平行数组（点/路径/日期）必须在同一循环内一起过滤** | `gpsPts_`/`gpsPaths_`/`gpsDates_` 按下标对齐（`enterCountry` 用 `gpsPaths_[i]` 配 `gpsPts_[i]`，MapView.cpp:2304）。只在绘制层过滤 → 三者长度不一致 → 国家视图把照片路径配到错误足迹点，且**不报任何错**。铁律：任何改变可见集合的操作（年份筛选/隐私门）必须经唯一入口 `MapPage::syncFootData()` |
| 22 | **★门禁断言的期望值绝不可依赖被测开关（如 `expect = broken ? A : B`）** | `LA_MAP_YEAR_QA` 首版把 `expect` 绑在 `broken` 标志上 → 反例注入 6 点时 `expect` 也变成 6 → **自证通过、反例不红**。铁律：期望值恒为规格值，反例必须让它**不等**；实测反例不红时，先怀疑断言弱（台账铁律 11 的同一条，此处是它的变体） |
| 23 | **★手写 `.ts` 条目必须转义 `& ' < >`，否则 `lrelease` 静默丢弃** | 2.13.0 追加「▶ 播放足迹」等 2 条时未转义 `'` → XML 解析失败 → `lrelease` 报 "254 finished" 看似成功，**实则那 2 条根本没进字典**（`grep` 命中 0），英文模式静默回落中文。铁律：追加后必须 `grep` 核验条目在文件中，且 `lupdate` 复跑须报 **`0 new`**（不是"很少 new"） |
| 24 | **★补 i18n 串禁跑 `lupdate` 改写 ts，只手工追加** | `lupdate` 会引入 300+ 行 `<location>` 噪音**并删掉既有翻译**（实测 `-7` 行，如 `Play This Region` 被冲掉）。正解：`rindex('</message>')`+`index('</context>')` 定位后手工追加 → 实测 diff `+16/-0`，location 稳定 299 |
| 25 | **★门禁探针改数据必须经 setter，禁直接赋值 `gpsPts_`** | `qaShootHeatRamp` 初版直接 `gpsPts_.append(...)` → `densDirty_` 未置位 → `computeDensity` 沿用真实库 6425 点的旧密度（实测 `dmin=311 dmax=3268`，三档判定全被真实库支配）。**这是台账铁律 12 的第二次复发**，凡涉密度/弧线缓存的探针必查 setter |
| 26 | **★门禁注入的测试点簇必须实测密度分离度** | 三簇若落在 `computeDensity` 同一网格（cell=22.0）内，密度会相同、三档塌成两档（实测中/高簇同为 52）。设计后必须用脚本复算各簇 density 是否真落在 `<3 / 3-7 / >=8` 三区间 |
| 27 | **★alpha 混合的渲染结果无法可靠反推档位/层级** | 热力是径向渐变 + alpha 混合，合成后像素与纯色参考的偏差远大于分档间距 → 任何像素归类阈值都在「过宽→低档抢匹配全部」与「过窄→全不匹配」间死锁（实测容差 0.18 → t0=801/t1=0；容差 0.045 → 全 0）。正解：**断言纯函数返回值互不相同**（`heatRamp(1/5/50).c0` 三色不等）**+ 独立统计宽泛像素数**（如暖橙系 `r>g+30`）作存在性佐证 |
| 28 | **★超长 `fprintf` 格式串用双参数短行，禁单行 130+ 字符** | 单行 14 个 `%02x` 的格式串在 MinGW GCC 下报 `expected ')' before 'int'`（列号 137 > 行长 136，疑似超长行解析异常）；改为两行短串（`graded/warm/dmin/dmax/broken` + `tiers=%d,%d,%d`）后一次通过。**排查提示：报此类"看起来完全合法却语法错"时，先怀疑行长/超长字面量，而非反复数括号引号** |
| 29 | **★门禁不得依赖本机外部服务状态（如 LLM 在线与否）** | `LA_AGENT_SMOKE` 探测真�� Ollama → 在线时走在线推理耗时 15.9–20.3s，**逼近 20s 看门狗预算** → 被 `no-exit-request` 误杀，且此前多轮误判为「负载噪声」。正解：门内把 `LA_LLM_URL` 固定指向**关闭端口**（`127.0.0.1:9`）强制走兜底 → 20211ms→1183ms，两次全绿。铁律：断言必须与「用户机器上开了什么服务」无关；真实在线推理属集成测试，不进 PR 门禁 |
| 30 | **★`[KILL]` 排查必须实测到底，禁止停在第一个假设** | `LA_LUMEN_SMOKE` 连续 KILL（25s 超时）。**错误假设①**：「动态壁纸占 CPU」→ 停掉 `webwallpaper64`（负载 60%→30%）后**仍 KILL，假设被证伪**。**错误假设②**：「大图逐像素 MAD 慢」→ 实测图仅 0.15 Mpx。**最终实测取证**：给足 120s → `exit=0` + `LA_LUMEN_SMOKE PASS`（90 行输出）；精确计时 **66.6s**。结论：**功能完全正常，纯耗时超预算**。铁律：KILL 类问题必须 (1) `git stash` 对照基线 exe 证明非本轮引入、(2) 给足超时直跑看是否 exit=0、(3) 精确计时定位差距；**三者缺一就下结论 = 猜** |
| 31 | **★`measuredMs` 会失真，必须定期用 `-Timing` 重新实测** | `LA_LUMEN_SMOKE` 的 `measuredMs` 记录为 7431ms，实际 **66585ms（9 倍差）** → 固定 25s 预算下稳定 KILL。E8 断言只校验字段**存在**，不校验与 runner 预算**一致**。铁律：新增/改动重计算门后必须重跑 `-Timing`；门成本 > runner 预算时用门级 `timeoutSec` 显式声明 |
| 32 | **★门表项是 hashtable，`PSObject.Properties` 不含其键** | runner 读门级字段用 `$g.PSObject.Properties.Name -contains "timeoutSec"` → **恒为 false**，门级超时静默失效（表现为「配了却没生效」）。正解：`$g.ContainsKey("timeoutSec")` + `$g["timeoutSec"]`。同坑：`Where-Object { $_.n -eq ... }` 对 hashtable 也不按 `.n` 匹配 |

## 1. 迭代流程（8 步，一步都不省）

```
① 对齐需求 → ② 现状取证 → ③ 根因定位 → ④ 方案（主+备选，写清取舍）
→ ⑤ 实施（小步、可回退）→ ⑥ QA 实测（门 + 新增断言）→ ⑦ 打包/提交 → ⑧ 记忆 + 台账
```

- **① 对齐需求**：功能是什么、目标层级、约束（能否改数据结构/升版本）。影响面大的先讲后做。
- **② 取证**：读代码到具体行；要日志/计数/截图；**禁止凭印象下结论**。
- **③ 根因**：能回答「为什么是它」，引用具体代码行/API 行为；区分「已确认」与「推测」。
- **④ 方案**：至少一个主方案 + 风险点 + 需要用户拍板的地方。
- **⑤ 实施**：一次一件事；改完立刻 `grep -n` 核验（见 §5 补丁规范）。
- **⑥ QA**：跑对应门；**新增 bug 必须新增一条可断言的 QA**（不许只靠肉眼）。
- **⑦ 打包**：`release.ps1` 重出 zip；`git commit` 写清「现象→根因→改法→实测数据」。
- **⑧ 记忆**：`.workbuddy/memory/YYYY-MM-DD.md` 追加；跨迭代沉淀进 `MEMORY.md`；本文件 §7 台账留一行。

- 门控要在 `main.cpp` 的 `animOk` 条件里并列排除，否则被开场动画分支拦截。

## 4. 编码规范（地图模块）

- **坐标**：预投影 `eqX(lon)=(lon+180)/360*1000`、`eqY(lat)=(90-lat)/180*500`，`MAP_W=1000, MAP_H=500`。
- **世界变换**（唯一真源）：`scale = dst.height()/MAP_H*worldZoom_`，`dst=rect().adjusted(8,8,-8,-8)`；横向 `driftPx_`（回绕）、纵向 `worldOffY_`（`worldOffYClamped()` 夹取）。
- **分层**：静态 = 网格/省面/国界/标签/足迹点（bake 进 `viewPix_`）；动态 = 航线流动虚线 + 爆炸弹层。
- **缓存失效**：`invalidateViewCache()` 于 enter*/goUp/resize/setGpsPoints；`densDirty_`、`arcTargetsDirty_` 于 setGpsPoints/setArcRegionIds。
- **交互语义**：世界点国家→（专辑 10 国）省视图 /（其余）国家视图；省面点→省视图；空白→返回上一级；爆炸卡片→灯箱。
- **动效**：`reduceMotion_` 时直达终态；`MotionPref.h` 常量集中管理。

## 5. 补丁操作规范

- 源文件 **CRLF**；多行 heredoc 易失配 → 用 Python「读 → 替换 → `assert(count==1)` → 写回」。
- `Edit` 工具存在**静默不落盘**：改完必 `grep -n` 核验；CRLF 文件长片段匹配失败时改单行锚点。
- 头文件改信号/方法后必查**重复声明**（`cannot be overloaded` 典型报错）。
