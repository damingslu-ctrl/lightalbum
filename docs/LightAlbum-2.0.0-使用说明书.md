# 光影集 LightAlbum 2.0.0 · 使用说明书

> **定位声明**：LightAlbum 2.0.0（native 版）是唯一正式分发形态——一个**零云端、纯本地**的 Windows 桌面照片管理客户端。发行物为单文件压缩包 `LightAlbum-2.0.0-win64.zip`（约 16.6 MB），旧 1.x Python 打包版本已全部停发并清理。
>
> 2.0.0 的能力面：**图库浏览 / 足迹地图 / 智能选片 / 修图实验室（双引擎）/ AI 美图 / 原生导入器**。所有处理均在你的电脑上完成，不向任何服务器发送照片或数据。

---

## 1. 安装与启动

1. 解压 `LightAlbum-2.0.0-win64.zip` 到任意目录（无需安装器、无需管理员权限、无注册表写入）。
2. 双击 `LightAlbum.exe` 启动。窗口标题显示「光影集 LightAlbum 2.0.0」。
3. **首次使用**：程序启动后自动读取默认库；若库为空，点击顶栏「导入目录」即可建立你自己的照片库（见第 3 节）。

### 数据存放位置（默认，可用环境变量改）

| 内容 | 默认路径 | 环境变量覆盖 |
|---|---|---|
| 照片库（SQLite） | `D:\lightalbum\library.db` | `LA_DB` |
| 缩略图缓存 | `D:\lightalbum\thumbs\` | `LA_THUMBS` |

- 这两个路径与旧 1.x 版本**完全兼容**：已有库直接被读取，缩略图缓存互相命中，无需迁移。
- 若默认盘符不存在，可用环境变量指向任意位置，例如（CMD）：
  `set LA_DB=E:\photo\library.db` 后再启动。

## 2. 主界面

左侧图标栏八区：**首页 / 足迹 / 图库 / 选片 / 修图 / 美图 / 日志 / 关于**；顶栏含标题、搜索框、导入目录按钮；首页与足迹页顶部有 KPI 条（照片总数、足迹省份等统计）。

## 3. 导入照片（原生导入器）

点击顶栏「**导入目录**」：

1. 选择一个照片根目录（子目录会递归扫描；`相机原始/缓存/回收站` 等辅助目录自动跳过）。
2. 扫描在后台线程进行，不卡界面；可随时取消。
3. 完成后弹出汇总（新增/已存在/跳过），可选择重启程序载入新库。

导入器行为细节：

- 读取每张照片的 **EXIF**（拍摄时间、相机、镜头、焦距、光圈、快门、ISO、GPS 坐标、方向等）——**缺失项如实留空**，显示为 `—`，绝不编造。
- 自动生成缩略图，缓存键与旧版共享（同一文件不会重复生成）。
- **增量安全**：重复导入同一目录时，未变化的文件直接跳过；文件被删除后重新导入会自动恢复；删除照片的评分等元数据不会被导入器覆盖。
- 支持格式：JPEG / PNG / TIFF 等常见格式（按文件内容签名识别，扩展名标错也能正确读取 EXIF）。HEIC 与 RAW 目前不解析 EXIF（RAW 只做去重与分辨率检测）。
- 云盘占位文件（OneDrive 等）会被识别并标记，不会当作有效照片。

## 4. 图库（浏览）

- 网格缩略图 + 底部**胶片条**快速切换；点击打开**灯箱**全屏查看，支持滚轮缩放（以鼠标为锚点）、拖移、适屏。
- 顶栏搜索框按标题/路径过滤。
- 照片列表来自 `library.db`，程序对库**只读**（评分等由外部流程写入，不会在浏览时被改动）。

## 5. 足迹（地图）

- **零外链地图**：世界地图与 233 省多边形数据编在 exe 内，离线可用，无需联网加载瓦片。
- **三级下钻**：世界 → 国家 → 省。有 GPS 的照片按真实坐标落点。
- **离线逆地理编码**：启动时自动把 GPS 坐标归属到国家/省份（纯本地点内多边形计算 + 城市最近邻兜底），KPI「足迹省份」即由此点亮。
- 诚实原则：落在覆盖范围之外（外海、未收录国家）的照片**留空不猜**。

## 6. 智能选片

对照片目录做本地筛选（`选片` 页）：

- **去重**：MD5 完全重复 + 感知哈希（pHash）相似聚类；
- **质量筛选**：模糊（拉普拉斯清晰度）、曝光异常检测；RAW 文件只做去重与分辨率检查，**不参与模糊/曝光淘汰**（防止误杀原始文件）；
- 结果分为 候选 / 废片 / 精选 三组展示（7 项 KPI），可导出归档。

## 7. 修图实验室（核心）

`修图` 页，全部处理零云端：

- **手动滑杆**：曝光/亮度/对比/清晰/自然饱和/饱和度/白平衡/锐化/高光-阴影/暗角 等 13 项；
- **16 个预设**：下拉即套用；
- **「智能增强」**：本地规则引擎（Lumen 测量 → 推荐参数），无任何外部依赖；
- **「AI 智能体」**（可选增强，见第 9 节）：由本地大模型读照片测量值给出修图方案，自动回填参数并应用；
- **几何编辑**：旋转 90°、水平/垂直翻转、拉直 ±10°、按比例裁剪（1:1/4:3/3:2/16:9）与**交互裁剪**（四角手柄 + 三分线）；
- **画笔蒙版**：局部涂抹后，色调只作用于涂抹区域；
- **对比视图**：单幅内左右拖动分割线，对比原图与修后；
- **导出副本**：预览所见即导出所得（几何 → 修图 → 蒙版固定流水线）。

## 8. AI 美图

`美图` 页为风格化预设画廊：16 种风格卡片（含缩略图预览），点选套用 + 大图 before/after + 智能增强 + 导出副本。

## 9. 接入本地 AI 智能体（可选）

「AI 智能体」依赖本机运行的 [Ollama](https://ollama.com)：

1. 安装 Ollama 并拉取模型：`ollama pull qwen3.5:4b`；
2. 保持 Ollama 运行（默认监听 `127.0.0.1:11434`）；
3. 在修图页点「AI 智能体」，可在弹窗输入修图目标（如「风光通透」「胶片感」）。

行为说明：

- 程序**只发送照片的客观测量值**（亮度/色偏/噪点/EXIF 等），不发送照片本身；
- 模型首次调用需冷加载（约 30 秒），之后每次约 2–3 秒；
- **Ollama 未运行或输出非法时，自动回退到本地规则推荐**，并在界面标注来源，不会失败卡死；
- 除回环地址外不访问任何网络——程序没有任何云端接口。

## 10. 隐私与数据安全

- 全部功能**零云端**：无遥测、无账号、无联网上传；
- 照片库是标准 SQLite 文件，可随时备份/迁移；
- 程序对库文件只读（导入器写库除外），浏览与修图不会改动你的原片。

## 11. 已知边界（设计取舍，非缺陷）

| 项目 | 状态 |
|---|---|
| HEIC/HEIF 照片 | 不解码、不读 EXIF |
| RAW 文件 | 只做去重/分辨率，不解析 EXIF |
| AI 消除（内容擦除） | 表单壳，需自行接入本地 inpainting 模型（`LA_INPAINT_MODEL`） |
| 人物识别 / CLIP 分类 / 私密库 | 未包含（上层 AI/实验性功能按「零云端核心客户端」定位省略） |
| AI 智能体 | 需本机 Ollama；无 Ollama 时自动用本地规则 |

## 12. 高级：环境变量一览

| 变量 | 作用 | 默认 |
|---|---|---|
| `LA_DB` | 照片库路径 | `D:/lightalbum/library.db` |
| `LA_THUMBS` | 缩略图目录 | `D:/lightalbum/thumbs` |
| `LA_LLM_URL` | Ollama 地址 | `http://127.0.0.1:11434` |
| `LA_LLM_MODEL` | 智能体模型 | `qwen3.5:4b` |
| `LA_INPAINT_MODEL` | AI 消除模型槽位 | （空 → 功能诚实挂起） |

## 13. 故障排查

| 现象 | 处理 |
|---|---|
| 启动报「库打开失败」 | 检查 `LA_DB` 路径是否存在/被占用；或用环境变量指向有效库 |
| 足迹省份为 0 | 正常现象之一：照片无 GPS 或落在覆盖范围外（诚实留空） |
| AI 智能体秒出结果但标注「本地规则」 | Ollama 未连接或模型未就绪；确认 `ollama serve` 在运行且已 `pull qwen3.5:4b` |
| AI 智能体第一次很慢 | 模型冷加载（约 30s），第二次起为热调用 |
| 缩略图显示异常 | 关闭程序后删除 `LA_THUMBS` 下对应文件即可重建（缓存键含 mtime/大小，安全） |
