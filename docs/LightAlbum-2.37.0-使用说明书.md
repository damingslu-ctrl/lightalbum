# 光影集 LightAlbum 2.37.0 · 使用说明书

> **定位声明**：LightAlbum（native 版）是唯一正式分发形态——一个**零云端、纯本地**的 Windows 桌面照片管理客户端。发行物为单文件压缩包 `LightAlbum-2.37.0-win64.zip`，解压即用；旧 1.x Python 打包版本已全部停发并清理。
>
> **本版能力面**：图库浏览 / 自动故事相册 / 足迹地图（轨迹+热力+按年筛选+国家省市三级下钻）/ 智能选片 / 修图实验室（双引擎 + **AI 消除真引擎**）/ AI 美图 / 相册聚类 / 相似照片去重 / AI 场景分类 / 人脸识别与人物聚类（**两遍精炼**）/ 隐私库（**全链路一致过滤**）/ 中英双语 / 无障碍键盘操作 / 高 DPI 适配 / 统一动效引擎 / **设计语言 v2 地基层（配色·字阶·几何单源化）** / 原生导入器（含 iCloud 相册）/ RAW 与视频（2.28.0 起）。所有处理均在你的电脑上完成，不向任何服务器发送照片或数据。
>
> 为此发布包内**随附三组第三方运行时**（均为独立进程调用，不与本程序链接）：
> LibRaw（约 3.5 MB，LGPL/CDDL 双许可）、FFmpeg（约 200 MB，GPL-3.0，仅取抽帧与读元数据能力）、
> **AI 消除执行器**（inpaint.exe + ONNX Runtime + LaMa ONNX 模型，合计约 210 MB）。
> **因此本版压缩包明显大于以往版本**（约 280 MB），这是为 RAW / 视频 / AI 消除所付出的体积代价。
>
> 三者都是**按需降级**的——缺少对应文件时，相应功能被安静地跳过或诚实提示「模型未就绪」，其余功能完全不受影响，绝不产生没有缩略图的空卡片或假成功。

## 1. 安装与启动

1. 解压 `LightAlbum-2.37.0-win64.zip` 到任意目录（无需安装器、无需管理员权限、无注册表写入）。
2. 双击 `LightAlbum.exe` 启动。窗口标题显示「光影集 LightAlbum 2.37.0」。
3. **首次使用**：程序启动后自动读取默认库；若库为空，点击顶栏「导入」即可建立你自己的照片库（见第 3 节）。

### 数据存放位置（默认，可用环境变量改）

| 内容 | 默认路径 | 环境变量覆盖 |
|---|---|---|
| 照片库（SQLite） | `D:\lightalbum\library.db` | `LA_DB` |
| 缩略图缓存 | `D:\lightalbum\thumbs\` | `LA_THUMPS` |

- 这两个路径与旧 1.x 版本**完全兼容**：已有库直接被读取，缩略图缓存互相命中，无需迁移。
- 若默认盘符不存在，可用环境变量指向任意位置，例如（CMD）：
  `set LA_DB=E:\photo\library.db` 后再启动。

## 2. 主界面

左侧图标栏八区：**首页 / 足迹 / 图库 / 选片 / 修图 / 美图 / 日志 / 关于**；顶栏含标题、搜索框、导入按钮与隐私库锁；首页与足迹页顶部有 KPI 条（照片总数、足迹省份等统计）。页面切换与局部反馈动效自 2.34.0 起由**统一动效引擎**驱动（见第 14 节）。

## 3. 导入照片（原生导入器）

点击顶栏「**导入**」下拉，两个入口：

- **导入目录**：选择任意照片根目录（子目录递归扫描；`相机原始/缓存/回收站` 等辅助目录自动跳过）。
- **导入 iCloud 相册**：自动探测本机 iCloud 照片目录（`%USERPROFILE%\Pictures\iCloud Photos\Photos` 等三个候选路径），**空目录会被拒绝**以免误报「已找到」。

扫描在后台线程进行，不卡界面；可随时取消。完成后弹出汇总（新增/已存在/跳过）。

导入器行为细节：

- 读取每张照片的 **EXIF**（拍摄时间、相机、镜头、焦距、光圈、快门、ISO、GPS 坐标、方向等）——**缺失项如实留空**，显示为 `—`，绝不编造。
- 自动生成缩略图，缓存键与旧版共享（同一文件不会重复生成）。
- **增量安全**：重复导入同一目录时，未变化的文件直接跳过；删除照片的评分等元数据不会被覆盖。
- 云盘占位文件（OneDrive 等）会被识别并标记，不会当作有效照片。
- RAW（2.28.0 起）解码缩略图与 EXIF；视频（2.28.0 起）入库并抽帧封面，与照片同为受支持格式。

## 4. 图库（浏览）

- 网格缩略图 + 底部**胶片条**快速切换；点击打开**灯箱**全屏查看，支持滚轮缩放（以鼠标为锚点）、拖移、适屏。
- **灯箱加载原图**：先秒出缩略图，后台渐进加载原图并淡入替换；加载失败诚实降级不黑屏。2.33.0 起灯箱索引化，大库翻图定位更快。
- 顶栏搜索框按标题/路径过滤；支持**多选**（Ctrl/Shift）与批量工具条（★评分 / 🔒私密 / 标记待删）。
- 大库下已做**窗口化虚拟化 + 两级缩略图缓存**，数千张照片滚动依旧流畅。
- **缩略图骨架屏**：未解码卡片显示 shimmer 骨架占位，解码完成平滑替换；缺画出稳定缺失态。动画尊重系统「减少动态效果」设置。

### 4.1 自动故事相册（2.32.0 新增）

图库页顶部一条**故事条**，一键把照片组织成「可以讲述的瞬间」。完全在视图层聚合，**不写入照片库**——原始数据不受影响，关闭筛选即回完整图库。

- **按「地点 + 时间窗口」自动分组**：同一地点、拍摄间隔不超过阈值（默认 5 天）的连续照片归为一个故事；地点先取省市、再退回大区、最后「未知地点」兜底，绝不编造坐标归属。
- **人物圆形头像墙**：故事条左侧展示已识别人物的圆形头像，点击只看该人物照片。
- **守恒保证**：分组是纯函数计算，输入多少张输出还是多少张——任何照片都不会被悄悄丢弃（由自动化门禁断言）。
- **规模封顶**：故事条最多展示 60 个分组，保证界面永远流畅。
- **一键开关**：点击故事条开启/关闭故事筛选。

## 5. 足迹（地图）

- **零外链地图**：世界地图与多国省多边形数据编在 exe 内，离线可用。
- **三级下钻**：世界 → 国家 → 省。有 GPS 的照片按真实坐标落点。
- **离线逆地理编码**：GPS 坐标归属到国家/省份（点内多边形计算 + 城市最近邻兜底）。
- **轨迹层 / 热力层 / 按年筛选**三种足迹视图随时切换。
- 诚实原则：落在覆盖范围之外的照片**留空不猜**。

## 6. 智能选片

对照片目录做本地筛选（`选片` 页）：

- **去重**：MD5 完全重复 + 感知哈希（pHash）相似聚类；
- **质量筛选**：模糊（拉普拉斯清晰度）、曝光异常检测；RAW 只做去重与分辨率检查，不参与模糊/曝光淘汰；
- 视频与照片同入选片流程（2.31.0 起支持视频卡片与抽帧封面）；
- **隐私一致（2.33.0 起）**：标记为私密的照片**不会进入**选片与相似去重结果（锁定态、解锁态均过滤），不会被间接曝光；
- 结果分为 候选 / 废片 / 精选 三组展示（7 项 KPI），可导出归档。

## 7. 修图实验室（核心）

`修图` 页，全部处理零云端：

- **手动滑杆 12 项**：曝光 / 亮度 / 对比 / 清晰 / 自然饱和 / 饱和 / 色温 / 色调 / 锐化 / 高光 / 阴影 / 暗角；
- **16 个预设** + 「智能增强」（本地规则引擎，无外部依赖）；
- **撤销栈**：任一步可回退；
- **几何编辑**：旋转、翻转、拉直 ±10°、比例裁剪与交互裁剪；
- **画笔蒙版**：局部涂抹后色调只作用于涂抹区域；
- **对比视图**：左右分割线对比原图与修后；
- **导出副本**：预览所见即导出所得；
- **★AI 消除（2.35.0 起为真引擎）**：涂抹要移除的物体，本地 LaMa 模型补全背景。执行器是**独立子进程**（`inpaint.exe` + ONNX Runtime + 随包模型），零云端、崩溃只影响当次任务、自动重拉；2.36.0 起推理在专属线程，**秒级计算期间界面完全不冻结**，可看到「处理中」状态。未随附模型时诚实提示「模型未就绪」，绝不假成功。
- **「AI 智能体」**（可选，见第 9 节）：本地大模型读测量值给出修图方案。

## 8. AI 美图

`美图` 页为风格化预设画廊：16 种风格卡片（含缩略图预览），点选套用 + 大图 before/after + 智能增强 + 导出副本。

## 9. 接入本地 AI 智能体（可选）

「AI 智能体」依赖本机运行的 [Ollama](https://ollama.com)：

1. 安装 Ollama 并拉取模型：`ollama pull qwen3.5:4b`；
2. 保持 Ollama 运行（默认监听 `127.0.0.1:11434`）；
3. 在修图页点「AI 智能体」，可输入修图目标（如「风光通透」「胶片感」）。

行为说明：

- 程序**只发送照片的客观测量值**，不发送照片本身；
- Ollama 未运行时自动回退本地规则推荐并标注来源；
- 除回环地址外不访问任何网络。

## 10. 智能检索（图库聚类条）

图库上方聚类条提供四类**本地 AI 能力**（服务启动见第 11 节），全程本机完成：

| 按钮 | 作用 | 产出 |
|---|---|---|
| **相册聚类** | 按省份 / 年份 / 城市 / 大区等维度自动分组 | 簇 chips，点击即筛选 |
| **相似照片** | MD5 + pHash 找出相似/重复照片 | 分组浏览对话框，可批量标记「待删」（非破坏性，可撤销）；私密照不参与（2.33.0） |
| **AI 分类** | 接本地 CLIP 场景模型 | 8 类场景标签 + chips 筛选 |
| **识别人物** | 接本地人脸服务检测人脸 | 人物标签写入，可右键重命名 |
| **智能聚类** | 按人脸特征自动区分不同人物 | 自动归组「人物N」，可逐个改名 |

要点：

- **智能聚类两遍精炼（2.35.0 起）**：贪心种子 + 至多 3 轮质心迭代，结果不再依赖照片处理顺序、同人归组更准；一次性运算在后台进行（约 25–30 秒，界面不冻结）。
- **AI 写库单写者（2.33.0 起）**：分类/识人等后台运算只计算，写回统一排队到界面线程执行，杜绝并发写库的数据竞争。
- **已标注的照片不会被覆盖**；聚类编号防撞号；多人合影按置信度最高的代表脸归类。

## 12. 隐私库

- 顶栏锁图标可对**指定照片**加私密标记并设口令；
- 浏览时可一键隐藏私密照片；
- **2.33.0 起隐私一致**：私密照片不仅从浏览隐藏，也**不参与**智能选片、相似去重等下游处理；
- 私密标记非破坏性（只隐藏不删除），口令只在本机校验。

## 13. 中英双语

- 界面文案已完整国际化（2.33.0 补齐全部新增串，312 条完成翻译）：默认按**系统显示语言**选择中文或英文；
- 强制指定：`LA_I18N_LANG=en`（或 `zh`）。

## 14. 无障碍、动效与显示适配

- 地图、灯箱均可**完全键盘操作**（`+`/`-`、方向键、`Enter` 下钻、`Esc` 返回、`←`/`→` 翻图）；
- 所有可聚焦控件有**可见焦点环**；文字对比度符合 WCAG AA；
- **高 DPI 适配**：125% / 150% / 200% 自动按显示器缩放渲染；
- **统一动效引擎（2.34.0 起）**：导航过渡、灯箱横滑、骨架脉冲、星标/芯片回弹、选片红心动效全部由同一纯函数引擎（曲线族 + 错峰 + 预设表）驱动；系统开启「减少动态效果」时**单点兜底**——所有动效直接收敛到终态、不起定时器。

## 15. 隐私与数据安全

- 全部功能**零云端**：无遥测、无账号、无联网上传；AI 消除子进程同样不发起任何网络请求；
- 三个可选 AI 服务只允许本机回环地址，程序拒绝任何外部地址；
- 照片库是标准 SQLite 文件，可随时备份/迁移；
- 修图、美图、分类均「调整参数 → 导出副本」，**不修改原片**；故事相册不写库。

## 16. 已知边界（设计取舍，非缺陷）

| 项目 | 状态 |
|---|---|
| AI 消除（内容擦除） | **2.35.0 起为真引擎**（独立子进程 + 随包 LaMa ONNX，零云端）；**2.36.0 起异步**，推理期间界面不冻结。模型按 512 分辨率规格补全，超大图的精细度以导出副本为准；缺模型时诚实提示「模型未就绪」 |
| 人脸聚类耗时 | 两遍精炼为一次性后台运算，约 25–30 秒（换取顺序无关与归组质量），不阻塞界面 |
| 多人同框照片 | 按置信度最高的代表脸归为一人，不做逐脸分离 |
| 重新聚类 | 需先清空目标照片的人物标注（本版本不提供自动重置按钮） |
| 灯箱原图 | 后台渐进加载，超大图（约 4000 万像素以上）解码有预算保护，超时保持缩略图 |
| RAW / 视频 | 2.28.0 起支持（解码缩略图、EXIF、抽帧、播放、磁盘缓存）；外部解码器缺失时对应格式优雅跳过 |
| 界面图标 | 少量角落仍使用 emoji 字符图标；矢量图标体系（qrc-SVG）在后续阶段铺开，本版未动图标 |
| 弹出菜单阴影 | 顶层菜单为系统原生窗口，widget 层阴影无法绘制——如实不带阴影（对话框与灯箱已获得浮层阴影，见第 19 节） |

## 18. 故障排查

| 现象 | 处理 |
|---|---|
| 启动报「库打开失败」 | 检查 `LA_DB` 路径是否存在/被占用；或用环境变量指向有效库 |
| 足迹省份为 0 | 正常现象之一：照片无 GPS 或落在覆盖范围外（诚实留空） |
| AI 分类 / 识别人物 提示「服务未就绪」 | 按第 11 节启动对应本地服务；仅支持本机回环地址 |
| AI 消除提示「模型未就绪」 | 确认 `3rdparty/lama/bin/` 内执行器与模型文件完整（见第 17 节槽位说明）；缺失时相应功能诚实挂起，其余不受影响 |
| AI 消除点「应用」后显示处理中 | 正常——本地模型推理需要数秒，界面可继续操作（2.36.0 异步） |
| 智能聚类后人物分组不理想 | 先把分错的照片改名归并；两遍精炼倾向于宁可多分不漏合 |
| 高分屏下界面发糊 | 确认未强制 `QT_SCALE_FACTOR`；程序按系统缩放渲染 |
| 故事条分组不符合预期 | 「地点 + 时间窗口」启发式视图，非缺陷（见 4.1） |

## 19. 本版新增（随 2.33.0–2.37.0 一并纳入本发行）

### 设计语言 v2 · P1 —— 界面地基层单源化（2.37.0）

- **配色 / 字阶 / 几何全量单源化**：全仓界面颜色字面量（415 处）、字号（68 处）、圆角（71 处）与间距（117 处）全部收编到 `Theme.h` 语义 token 唯一真源。外观零变化，但设计语言从此不再逐页漂移——后续全局调型只改一处。
- **新增语义 token**：`SOFT_IMG`（照片叠加文字暖灰）与 `GOLD_WASH`（金色按钮选中衬底）；人物色板 CAT1–8 命名归一化；一处历史色号 typo 全仓清退（翻译目录同步）。
- **浮层阴影诞生**：去重对话框与视频灯箱获得真浮层阴影（E2 档）；顶层弹出菜单是系统原生窗口，widget 层阴影无法绘出——如实跳过，不伪报。
- **设计债棘轮门 `LA_PALETTE_QA`（第 72 门）**：五计数基线（颜色字面量 / 字号 / 圆角 / 间距 / 译句 emoji）**只降不升**，任何新增字面量即刻变红。其中 30 处 emoji 字符图标债留待矢量图标体系偿还（本版未动图标）。
- **零行为变化**：照片库格式、缩略图缓存与数据契约完全不受影响——本升级只动表达层。

### AI 消除真引擎（2.35.0 + 2.36.0）

- 修图页「AI 消除」从占位壳升级为**真执行**：独立子进程 inpaint.exe（ONNX Runtime + LaMa ONNX），涂抹+应用即可移除物体并补全背景，**全程本机**。
