# 光影集 LightAlbum 2.21.0 · 使用说明书

> **定位声明**：LightAlbum（native 版）是唯一正式分发形态——一个**零云端、纯本地**的 Windows 桌面照片管理客户端。发行物为单文件压缩包 `LightAlbum-2.21.0-win64.zip`（约 17.4 MB），解压即用；旧 1.x Python 打包版本已全部停发并清理。
>
> 2.20.0 的能力面：**图库浏览 / 足迹地图（轨迹+热力+按年筛选）/ 智能选片 / 修图实验室（双引擎）/ AI 美图 / 相册聚类 / 相似照片去重 / AI 场景分类 / 人脸识别与人物聚类 / 隐私库 / 中英双语 / 无障碍键盘操作 / 高 DPI 适配 / 原生导入器（含 iCloud 相册）**。所有处理均在你的电脑上完成，不向任何服务器发送照片或数据。

---

## 1. 安装与启动

1. 解压 `LightAlbum-2.21.0-win64.zip` 到任意目录（无需安装器、无需管理员权限、无注册表写入）。
2. 双击 `LightAlbum.exe` 启动。窗口标题显示「光影集 LightAlbum 2.21.0」。
3. **首次使用**：程序启动后自动读取默认库；若库为空，点击顶栏「导入」即可建立你自己的照片库（见第 3 节）。

### 数据存放位置（默认，可用环境变量改）

| 内容 | 默认路径 | 环境变量覆盖 |
|---|---|---|
| 照片库（SQLite） | `D:\lightalbum\library.db` | `LA_DB` |
| 缩略图缓存 | `D:\lightalbum\thumbs\` | `LA_THUMPS` |

- 这两个路径与旧 1.x 版本**完全兼容**：已有库直接被读取，缩略图缓存互相命中，无需迁移。
- 若默认盘符不存在，可用环境变量指向任意位置，例如（CMD）：
  `set LA_DB=E:\photo\library.db` 后再启动。

## 2. 主界面

左侧图标栏八区：**首页 / 足迹 / 图库 / 选片 / 修图 / 美图 / 日志 / 关于**；顶栏含标题、搜索框、导入按钮与隐私库锁；首页与足迹页顶部有 KPI 条（照片总数、足迹省份等统计）。

## 3. 导入照片（原生导入器）

点击顶栏「**导入**」下拉，两个入口：

- **导入目录**：选择任意照片根目录（子目录递归扫描；`相机原始/缓存/回收站` 等辅助目录自动跳过）。
- **导入 iCloud 相册**：自动探测本机 iCloud 照片目录（`%USERPROFILE%\Pictures\iCloud Photos\Photos` 等三个候选路径），**空目录会被拒绝**以免误报「已找到」。

扫描在后台线程进行，不卡界面；可随时取消。完成后弹出汇总（新增/已存在/跳过）。

导入器行为细节：

- 读取每张照片的 **EXIF**（拍摄时间、相机、镜头、焦距、光圈、快门、ISO、GPS 坐标、方向等）——**缺失项如实留空**，显示为 `—`，绝不编造。
- 自动生成缩略图，缓存键与旧版共享（同一文件不会重复生成）。
- **增量安全**：重复导入同一目录时，未变化的文件直接跳过；删除照片的评分等元数据不会被覆盖。
- **支持格式（实测）**：JPEG / PNG / **HEIC**（Qt 可解码）；**RAW（`.dng` / `.arw`）与视频（`.mp4` / `.mov`）不解析 EXIF**——RAW 只做去重与分辨率检测，视频不纳入照片库（避免生成空白缩略图卡片）。
- 云盘占位文件（OneDrive 等）会被识别并标记，不会当作有效照片。

## 4. 图库（浏览）

- 网格缩略图 + 底部**胶片条**快速切换；点击打开**灯箱**全屏查看，支持滚轮缩放（以鼠标为锚点）、拖移、适屏。
- 顶栏搜索框按标题/路径过滤；支持**多选**（Ctrl/Shift）与批量工具条（★评分 / 🔒私密 / 标记待删）。
- 大库下已做**窗口化虚拟化 + 两级缩略图缓存**，数千张照片滚动依旧流畅。

## 5. 足迹（地图）

- **零外链地图**：世界地图与多国省多边形数据编在 exe 内，离线可用，无需联网加载瓦片。
- **三级下钻**：世界 → 国家 → 省。有 GPS 的照片按真实坐标落点。
- **离线逆地理编码**：自动把 GPS 坐标归属到国家/省份（纯本地点内多边形计算 + 城市最近邻兜底），KPI「足迹省份」即由此点亮。
- **轨迹层**：按拍摄时间把足迹连成路线，支持播放动画（播放头沿轨迹推进）。
- **热力层**：足迹密度以热力图呈现，配色带分级（经典 / 暖橙 / 熔岩 等）。
- **按年筛选**：足迹点已带时间维，可按年份过滤。
- 三种足迹视图（光点 / 轨迹 / 热力）可随时切换，互不影响。
- 诚实原则：落在覆盖范围之外（外海、未收录国家）的照片**留空不猜**。

## 6. 智能选片

对照片目录做本地筛选（`选片` 页）：

- **去重**：MD5 完全重复 + 感知哈希（pHash）相似聚类；
- **质量筛选**：模糊（拉普拉斯清晰度）、曝光异常检测；RAW 文件只做去重与分辨率检查，**不参与模糊/曝光淘汰**（防止误杀原始文件）；
- 结果分为 候选 / 废片 / 精选 三组展示（7 项 KPI），可导出归档。

## 7. 修图实验室（核心）

`修图` 页，全部处理零云端：

- **手动滑杆 12 项**：曝光 / 亮度 / 对比 / 清晰 / 自然饱和 / 饱和 / 色温 / 色调 / 锐化 / 高光 / 阴影 / 暗角；
- **16 个预设**：下拉即套用；**「智能增强」**由本地规则引擎（Lumen 测量 → 推荐参数）给出建议，无任何外部依赖；
- **撤销栈**：任一步可回退，不怕试错；
- **「AI 智能体」**（可选增强，见第 9 节）：由本地大模型读照片测量值给出修图方案，自动回填参数并应用；
- **几何编辑**：旋转 90°、水平/垂直翻转、拉直 ±10°、按比例裁剪（1:1/4:3/3:2/16:9）与**交互裁剪**（四角手柄 + 三分线）；
- **画笔蒙版**：局部涂抹后，色调只作用于涂抹区域；
- **对比视图**：单幅内左右拖动分割线，对比原图与修后；
- **导出副本**：预览所见即导出所得（几何 → 修图 → 蒙版固定流水线）。

## 8. AI 美图

`美图` 页为风格化预设画廊：16 种风格卡片（含缩略图预览），点选套用 + 大图 before/after + 智能增强 + 导出副本。

## 9. 接入本地 AI 智能体（可选）

「AI 智能体」依赖本机运行的 [Ollama](https://ollama.com)：

1. 安装 Ollama 并拉取模型：`ollama pull qwen3.5:4b`；
2. 保持 Ollama 运行（默认监听 `127.0.0.1:11434`）；
3. 在修图页点「AI 智能体」，可在弹窗输入修图目标（如「风光通透」「胶片感」）。

行为说明：

- 程序**只发送照片的客观测量值**（亮度/色偏/噪点/EXIF 等），不发送照片本身；
- 模型首次调用需冷加载（约 30 秒），之后每次约 2–3 秒；
- **Ollama 未运行或输出非法时，自动回退到本地规则推荐**，并在界面标注来源，不会失败卡死；
- 除回环地址外不访问任何网络——程序没有任何云端接口。

## 10. 智能检索（图库聚类条）

图库上方聚类条提供四类**本地 AI 能力**，均需先启动对应本地服务（见第 11 节），处理全程在本机完成：

| 按钮 | 作用 | 产出 |
|---|---|---|
| **相册聚类** | 按省份 / 年份 / 城市 / 大区等维度自动分组 | 簇 chips，点击即筛选 |
| **相似照片** | MD5 + pHash 找出相似/重复照片 | 分组浏览对话框，可批量标记「待删」（**非破坏性**，可撤销） |
| **AI 分类** | 接本地 CLIP 场景模型，自动打场景标签 | 8 类场景（风光/人像/夜景…）标签 + chips 筛选 |
| **识别人物** | 接本地人脸服务检测人脸 | 人物标签写入，可在 chips 上**右键重命名**为真名 |
| **智能聚类** | 按人脸特征自动区分不同人物 | 自动把「人物1/人物2/…」归组，随后可逐个改名 |

要点：

- **已标注的照片不会被覆盖**：聚类只处理尚未标注人物的照片，你改过的名字始终保留。
- **聚类编号防撞号**：自动生成的「人物N」会避开你已用过的编号。
- 多人合影的照片按**置信度最高的代表脸**归类（每张照片一个标签）。

## 11. 本地 AI 服务（可选，需自行启动）

上述 AI 功能均为**可选增强**，不启动时其余功能全部正常。三个服务都只监听本机回环地址，照片不会外传：

| 功能 | 服务 | 启动方式 | 默认端口 |
|---|---|---|---|
| AI 分类 | CLIP 场景分类服务 | `D:\lightalbum_ai\start_classifier.bat` | 8766 |
| 识别人物 / 智能聚类 | 人脸检测识别服务 | `D:\lightalbum_ai\face_server.py` | 8767 |
| AI 智能体 | Ollama | `ollama serve` | 11434 |

点对应按钮时若服务未就绪，程序会**明确提示**而非静默失败。

## 12. 隐私库

- 顶栏锁图标可对**指定照片**加私密标记，并设置口令；
- 浏览时可一键隐藏私密照片；
- 私密标记是**非破坏性**的（只是隐藏，不是删除或移动文件），口令只在本机校验。

## 13. 中英双语

- 界面文案已完整国际化：默认按**系统显示语言**选择中文或英文；
- 如需强制指定，启动前设置环境变量 `LA_I18N_LANG=en`（或 `zh`）。

## 14. 无障碍与显示适配

- 地图视图、照片灯箱均**可完全用键盘操作**（`+`/`-` 缩放、方向键平移、`Enter` 下钻、`Esc` 返回；灯箱 `←`/`→` 翻图）；
- 所有可聚焦控件有**可见焦点环**；
- 界面文字与背景对比度符合 WCAG AA 标准；
- **高 DPI 适配**：125% / 150% / 200% 缩放下界面与地图均清晰不糊（按显示器实际缩放自动渲染）。

## 15. 隐私与数据安全

- 全部功能**零云端**：无遥测、无账号、无联网上传；
- 三个 AI 服务**只允许本机回环地址**（`127.0.0.1` / `localhost`），程序会拒绝任何外部地址；
- 照片库是标准 SQLite 文件，可随时备份/迁移；
- 修图、美图、分类等**不修改你的原片**，均为「调整参数 → 导出副本」模式。

## 16. 已知边界（设计取舍，非缺陷）

| 项目 | 状态 |
|---|---|
| 视频文件（mp4/mov） | 不纳入照片库（导入时跳过） |
| RAW 文件（dng/arw） | 只做去重/分辨率，不解析 EXIF、不参与质量淘汰 |
| AI 消除（内容擦除） | 表单壳，需自行接入本地 inpainting 模型（`LA_INPAINT_MODEL`） |
| 多人同框照片 | 按置信度最高的代表脸归为一人，不做逐脸分离 |
| AI 智能体 | 需本机 Ollama；无 Ollama 时自动用本地规则 |
| 重新聚类 | 需先清空目标照片的人物标注（本版本不提供自动重置按钮） |

## 17. 高级：环境变量一览

| 变量 | 作用 | 默认 |
|---|---|---|
| `LA_DB` | 照片库路径 | `D:/lightalbum/library.db` |
| `LA_THUMPS` | 缩略图目录 | `D:/lightalbum/thumbs` |
| `LA_LLM_URL` | Ollama 地址 | `http://127.0.0.1:11434` |
| `LA_LLM_MODEL` | 智能体模型 | `qwen3.5:4b` |
| `LA_INPAINT_MODEL` | AI 消除模型槽位 | （空 → 功能诚实挂起） |
| `LA_I18N_LANG` | 强制界面语言（`en` / `zh`） | （空 → 跟随系统显示语言） |

## 18. 故障排查

| 现象 | 处理 |
|---|---|
| 启动报「库打开失败」 | 检查 `LA_DB` 路径是否存在/被占用；或用环境变量指向有效库 |
| 足迹省份为 0 | 正常现象之一：照片无 GPS 或落在覆盖范围外（诚实留空） |
| AI 分类 / 识别人物 提示「服务未就绪」 | 按第 11 节启动对应本地服务后再点；仅支持本机回环地址 |
| 智能聚类后人物分组不理想 | 聚类阈值偏保守（倾向于「宁可多分成几组」）；可先把分错的照片改名归并 |
| AI 智能体秒出结果但标注「本地规则」 | Ollama 未连接或模型未就绪；确认 `ollama serve` 在运行且已 `pull qwen3.5:4b` |
| AI 智能体第一次很慢 | 模型冷加载（约 30s），第二次起为热调用 |
| 高分屏下界面发糊 | 确认未强制设置 `QT_SCALE_FACTOR`；程序按系统实际缩放渲染 |
| 缩略图显示异常 | 关闭程序后删除 `LA_THUMPS` 下对应文件即可重建（缓存键含 mtime/大小，安全） |

## 附录 A：校验与复现（进阶）

发行包内附两个可校验文件：

- **`BUILDINFO.txt`**（SBOM 溯源）：本包由哪个 git commit、哪套 Qt / 编译器、哪种构建类型产出。
- **`MANIFEST.txt`**：包内**每一个文件**的 SHA256 与字节数。可用 `Get-FileHash` 逐个复核，确认包未被篡改。

另可用 PowerShell 自行验证版本一致性：`powershell -File release.ps1 -SelfTest` 会跑一遍打包契约自检（版本同步 / 手册 / 核心产物 / 清单一致 / 压缩包完整 / 许可证 / 清单可复现，共 7 条）。
